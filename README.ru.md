# Базовый эталонный шаблон репозитория

Этот репозиторий представляет собой каноническую базовую структуру для всех проектов.

## Состав шаблона
- `.githooks/` — Версионируемые хуки для невидимого фонового запечатывания коммитов в OpenTimestamps и валидации безопасности.
- `.github/workflows/ots-cron.yml` — Ночной workflow для автоматического забора и проверки доказательств Bitcoin.
- `.allowed_signers` — Список доверенных открытых ключей для верификации подписей коммитов и тегов.
- `SECURITY.md` — Политика безопасности и привязка к домену nada.mu.
- `CHANGELOG.md` — Структурированный журнал изменений по стандарту Keep a Changelog и Semantic Versioning.
- `docs/` — Живая документация (Архитектура, ADR, Планы, Идеи, Руководства на русском и английском).
- `scripts/`
  - `retrofit.sh` — Скрипт быстрого обновления любых репозиториев до этого стандарта.
  - `release.sh` — Инструмент формирования релиза (обновление changelog, подписанный тег, синхронизация OpenTimestamps).
  - `release-check.sh` — Универсальный шлюз релизов (проверка чистоты дерева, ветки main, SemVer-тега и changelog).

## Быстрый старт для новых проектов
1. Создать проект на основе шаблона:
   ```bash
   cp -r /Projects/Template /Projects/<ProjectName>
   cd /Projects/<ProjectName>
   git init
   git config core.hooksPath .githooks
   ```
2. Разрабатывать и тестировать в короткоживущих ветках (`feat/<topic>`).
3. Вливать в `main` после успешной проверки на staging.
4. Оформить релиз:
   ```bash
   scripts/release.sh v1.0.0
   ```
